# 🚀 Portfolio Estilo Visual Studio Code

Portfolio personal con diseño inspirado en Visual Studio Code, desarrollado con React, TypeScript y TailwindCSS.

## 🛠️ Tecnologías

- React 18
- TypeScript
- TailwindCSS
- Vite
- Lucide Icons
- Resend (para emails)

## 📦 Instalación

1. Clonar el repositorio
2. Instalar dependencias:
npm install
